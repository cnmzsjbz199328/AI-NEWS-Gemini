# 音色参考文件目录

这个目录用于存储默认的音色参考文件，用户也可以上传自定义音色文件。

## 目录结构

```
voice-references/
├── moderator/          # 主持人音色文件
│   ├── default.wav     # 默认音色
│   └── custom/         # 用户自定义音色
├── tom/                # Tom角色音色文件
│   ├── default.wav     # 默认音色
│   └── custom/         # 用户自定义音色
├── mark/               # Mark角色音色文件
│   ├── default.wav     # 默认音色
│   └── custom/         # 用户自定义音色
└── samples/            # 示例音频文件
    ├── preview-text.txt # 预览文本示例
    └── quality-test.wav # 音质测试文件
```

## 文件要求

### 音频格式要求
- **支持格式**: WAV, MP3, OGG, M4A, AAC
- **推荐格式**: WAV (最佳质量)
- **采样率**: 16kHz - 48kHz
- **位深度**: 16-bit 或 24-bit
- **声道**: 单声道或立体声
- **文件大小**: 最大 10MB

### 音频质量要求
- **录音环境**: 安静环境，minimal background noise
- **录音长度**: 10-60秒为最佳
- **语音内容**: 清晰的中英文混合语音
- **语调**: 自然、表达丰富

## 使用说明

1. **默认音色**: 系统提供的基础音色文件
2. **自定义音色**: 用户通过设置面板上传的音色文件
3. **音色克隆**: 使用 IndexTTS-2-Demo 进行音色克隆
4. **预览功能**: 上传后可以预览音色效果

## 技术实现

- 音色文件通过 localStorage 和 IndexedDB 进行本地存储
- 支持音色文件的增删改查操作
- 集成 IndexTTS-2-Demo API 进行音色克隆
- 提供音色预览和质量检测功能

## 注意事项

1. 音色文件会占用浏览器存储空间
2. 建议定期清理不使用的音色文件
3. 上传的音色文件仅在本地存储，不会上传到服务器
4. 音色克隆效果取决于原始音频文件的质量
